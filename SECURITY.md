# Security Policy

## Supported Versions

Jupiter Sonic is in active development. Only the latest release on the `main` branch receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of Jupiter Sonic and its users very seriously. Since the platform runs fully locally, local privilege escalation or arbitrary code execution are our highest priority concerns.

If you find any security vulnerabilities in the codebase, please do not open a public GitHub issue. Instead, report it privately:

1. **Email the developer** at **contact@supanroy.com** with details of the vulnerability.
2. Include a detailed description of the issue, step-by-step reproduction steps, and any proof-of-concept (PoC) scripts or audio clips.
3. We will acknowledge receipt of your email within 48 hours and work with you to patch the issue before public disclosure.
